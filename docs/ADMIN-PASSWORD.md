# 🔑 Админ паролін Render панелінен өзгерту

Пароль қабылданбай жатса немесе ұмытып қалсаңыз — осы нұсқаулық бойынша
2 минутта қалпына келтіресіз.

---

## Неге бұлай болады?

Пароль **дерекқорда** bcrypt hash түрінде сақталады. Ол бірінші деплойда
жасалады, ал дерекқор кейінгі деплойларда өмір сүре береді. Сондықтан
`ADMIN_PASSWORD` мәнін білмесеңіз, панельге кіре алмайсыз.

Жаңа кодта бұл шешілген: `ADMIN_PASSWORD` өзгерсе, сервер іске қосылғанда
дерекқордағы hash **автоматты жаңарады**.

---

## Қадамдық нұсқаулық

### 1-қадам · Render-ге кіру

https://dashboard.render.com → GitHub аккаунтыңызбен кіріңіз.

### 2-қадам · Веб-сервисті ашу

Тізімнен **`kz-history-rpg`** сервисін басыңыз.

> ⚠️ Абайлаңыз: тізімде екі жазба бар.
> - `kz-history-rpg` — 🟦 **Web Service** (керегі осы)
> - `kz-history-db` — 🟩 PostgreSQL дерекқоры (бұған тиіспейміз)

### 3-қадам · Environment бөліміне өту

Сол жақтағы мәзірден **Environment** таңдаңыз.

### 4-қадам · ADMIN_PASSWORD мәнін өзгерту

`ADMIN_PASSWORD` жолын табыңыз (мәні `••••••` болып жасырылған).

1. Жолдың оң жағындағы **✏️ Edit** белгішесін басыңыз
2. Ескі мәнді өшіріп, жаңа парольді жазыңыз
3. **Save changes** батырмасын басыңыз

**Пароль жоқ болса** — **+ Add Environment Variable** басып, қосыңыз:

| Өріс | Мән |
|---|---|
| Key | `ADMIN_PASSWORD` |
| Value | сіздің жаңа пароліңіз |

### 5-қадам · Деплойды күту

Save басқаннан кейін Render сервисті автоматты қайта іске қосады.
Жоғарғы оң жақта күй көрсетіледі:

```
Deploying…  →  Live ✅
```

Әдетте 2–4 минут алады.

### 6-қадам · Логтан растау

Сол жақтағы **Logs** бөлімін ашыңыз. Мына жол көрінуі керек:

```
[ADMIN] Пароль ADMIN_PASSWORD орта айнымалысынан жаңартылды.
[DB] postgres дайын.
🏰 Қазақстан тарихы RPG — http://localhost:3000
```

Осы жазу шықса — пароль жаңарды.

### 7-қадам · Тексеру

https://kz-history-rpg.onrender.com/admin → жаңа парольмен кіріңіз.

> 💡 Сайт «ұйықтап» қалған болса, бірінші ашылу ~30 секунд алады.

## Балама: панель арқылы өзгерту

Панельге кіре алатын болсаңыз, Render-ге бармай-ақ өзгертуге болады:

**`/admin` → ⚙ Баптау → Парольді өзгерту** → ағымдағы + жаңа пароль → Өзгерту

> ⚠️ Бірақ Render-де `ADMIN_PASSWORD` тұрса, ол әр рестартта басымдыққа ие
> болып, панельдегі өзгерісті қайтарып тастайды.
>
> **Тек панель арқылы басқарғыңыз келсе:** Render → Environment →
> `ADMIN_PASSWORD` жолын **мүлдем өшіріңіз** (🗑 белгішесі). Сонда пароль
> тек дерекқорда сақталады.

## Қай тәсілді таңдау керек?

| Жағдай | Тәсіл |
|---|---|
| Парольді ұмыттым | Render → Environment (жоғарыдағы 7 қадам) |
| Пароль есімде, ауыстырғым келеді | `/admin` → ⚙ Баптау |
| Парольді жиі ауыстырамын | Render-ден `ADMIN_PASSWORD` өшіріп, тек панельді қолданыңыз |

---

## Мәселе шықса

| Белгі | Себеп / шешім |
|---|---|
| Save басқаннан кейін де ескі пароль | Деплой аяқталмаған. Logs → `Live` күйін күтіңіз |
| Логта `[ADMIN]` жолы жоқ | Пароль өзгермеген (ескісімен бірдей) немесе деплой құлаған |
| «Пароль қате» әлі шығады | Бос орын кетіп қалған жоқ па? Мәнді қайта теріңіз |
| Кіру батырмасы жауап бермейді | Сайт ұйықтап қалған — 30 секунд күтіп, бетті жаңартыңыз |
| `Too many requests` | 15 минутта 20 әрекет шегі. Күтіңіз немесе басқа құрылғыдан кіріңіз |

## Ең соңғы амал (бәрі көмектеспесе)

Render → **`kz-history-db`** → **Connect** → `PSQL Command` көшіріп,
терминалда орындаңыз:

```sql
DELETE FROM settings WHERE key = 'admin_password_hash';
```

Содан кейін веб-сервисті қайта іске қосыңыз
(**Manual Deploy → Restart service**). Сервер `ADMIN_PASSWORD` мәнінен
жаңа hash жасайды.
