## 🚀 Жылдам бастау

### Талаптар

- **Node.js ≥ 18** (LTS 20 ұсынылады)
- npm ≥ 9
- (қосымша) Python 3 + numpy — аудионы қайта жасау үшін

### Орнату

```bash
git clone https://github.com/<user>/kz-history-rpg.git
cd kz-history-rpg

npm install          # тәуелділіктер + .env автоматты құрылады
npm run dev          # әзірлеу режимі (hot reload)
```

Ашыңыз:

| Бет | URL |
|---|---|
| 🎮 Ойын | http://localhost:3000 |
| 🔐 Админ панелі | http://localhost:3000/admin |

**Админ паролі (әдепкі):** `Akilbek8080` — `.env` немесе админ панелі арқылы өзгертіңіз.

### Барлық командалар

```bash
npm install      # тәуелділіктерді орнату
npm run dev      # әзірлеу сервері (--watch)
npm start        # production сервері
npm run build    # dist/ ішіне жинау (минификациямен)
npm test         # 21 end-to-end сынақ
npm run audio    # аудио файлдарын қайта генерациялау
npm run db:reset # дерекқорды тазарту (⚠ барлық нәтиже жойылады)
```

### Production іске қосу

```bash
npm run build
cd dist
npm ci --omit=dev
NODE_ENV=production JWT_SECRET="ұзын-кездейсоқ-жол" npm start
```

## 📄 PDF тапсырмалар

Бұл жобаның басты ерекшелігі — **тапсырмалар кодта жазылмайды**.

```
server/uploads/tasks.pdf   ← мұғалім жүктейтін файл
```

Файлды екі жолмен жаңартуға болады:

1. **Админ панелі → ⚙ Баптау → PDF тапсырмалар** бөліміне сүйреп тастаңыз
2. Немесе файлды тікелей `server/uploads/tasks.pdf` орнына көшіріңіз

Сервер файлдың өлшемі/уақыты өзгергенін байқап, тапсырмаларды **автоматты
қайта оқиды**. Қайта іске қосудың қажеті жоқ.

### PDF форматы

Парсер мұғалім жазатын кәдімгі құрылымды түсінеді:

```
1 бөлме. Сәйкестендіру. Барлығы 30 секунд берілсін. Әр дұрыс жауап +1 ұпай.
№  Сол жақ                 Оң жақ
1  Жүсіп Баласағұни     A  Құтты білік
2  Махмұд Қашғари       B  Диуани лұғат ат-Түрік
...

2 бөлме. Тест. Әр сұраққа - 15 сек берілсін.
1. Ең алғашқы адамдардың еңбек құралдары негізінен неден жасалды?
A) Темірден
B) Қоладан
C) Тастан
D) Мыстан
...
Жауап кілті
№ Жауабы  № Жауабы  № Жауабы
1 C       10 B      19 A
...
```

**Автоматты анықталатындар:**

| Элемент | Қалай танылады |
|---|---|
| Бөлме шекарасы | `N бөлме.` жолы |
| Тест | `A) B) C) D)` нұсқалары + «Жауап кілті» кестесі |
| Сәйкестендіру | `№ · сол жақ · әріп · оң жақ` кестесі |
| Timeline | Даталар тізімі + `Әріп Оқиға` тізімі + «Реті» кілті |
| Карточкалар | `А карточкалары` / `В карточкалары` + `Факт · Дұрыс жауап` |
| Уақыт лимиті | «Барлығы 60 секунд» / «Әр сұраққа - 15 сек» |
| Бірнеше бөлім | `I бөлім` / `II бөлім` — бір бөлмеде бірнеше кезең |

> **Ескерту:** парсер PDF кестелерін X/Y координаталары бойынша қалпына
> келтіреді, сондықтан көп жолға созылған ұяшықтар да дұрыс оқылады.

Ағымдағы PDF-тен алынған нәтиже:

| Бөлме | Түрі | Тапсырма саны |
|---|---|---|
| 1 | Сәйкестендіру | 10 |
| 2 | Тест | 25 |
| 3 | Сәйкестендіру (2 бөлім) | 20 |
| 4 | Хронология (Timeline) | 14 |
| 5 | Pair Matching | 10 |
| 6 | Тест | 15 |
| 7 | Сәйкестендіру + Карточкалар | 25 + 5 |
| **Барлығы** | | **124** |

## 🎮 Ойын механикасы

### Ағын

```
Басты бет → Тіркелу → Кейіпкер таңдау → Қамал
   ↓
1-бөлме → 2-бөлме → … → 7-бөлме → Нәтиже экраны
```

Бөлмелер **тек ретімен** ашылады: алдыңғысын аяқтамай келесісі ашылмайды.

### Жүрек жүйесі

Әр бөлме басталғанда **5 жан** беріледі:

```
❤️❤️❤️❤️❤️  →  ❤️❤️❤️❤️🤍  →  ❤️❤️❤️🤍🤍  →  ❤️❤️🤍🤍🤍  →  ❤️🤍🤍🤍🤍  →  🤍🤍🤍🤍🤍
                                                                        ↓
                                                                   GAME OVER
```

Жүрек толық бітсе — ойын **бірінші бөлмеден** қайта басталады
(бұл жаңа әрекет ретінде есептеледі).

### Ұпай жүйесі

| Оқиға | Ұпай |
|---|---|
| Әр дұрыс жауап | **+1** |
| Бөлмеде бірде-бір жүрек жоғалтпаса | **+5** |
| Бөлмедегі барлық тапсырма дұрыс | **+10** |

Максимум ұпай: `124 тапсырма + 7 × 15 бонус = 229`

### 3 әрекет ережесі

Әр студент (аты + тегі + тобы + оқу орны бойынша анықталады) тек **3 рет**
ойнай алады. 4-ші рет кіргенде:

> ⛔ **Сіз бұл ойынды орындау лимитін аяқтадыңыз.**

Шектеу сервер жағында тексеріледі — браузерден айналып өту мүмкін емес.

### Аяқталу экраны

Барлық бөлме біткенде үлкен экран шығады:

> 🎉 **Ай, маладес, Ақылбек Беделханұлына ұпайыңды көрсет!**

Көрсетілетін мәліметтер: жалпы ұпай · дұрыс жауап саны · қате жауап саны ·
дәлдік пайызы · жалпы уақыт · **әр бөлмеге кеткен уақыт** · Best Score.

## ☁️ Google Sheets (OPTIONAL)

Интеграция **міндетті емес**. Бапталмаса, жоба қалыпты жұмысын жалғастырады.

### Қосу

1. [Google Cloud Console](https://console.cloud.google.com/) → жоба құрыңыз
2. **Google Sheets API** қосыңыз
3. **Service Account** құрып, JSON кілтін жүктеңіз
4. Google Sheets кестесін құрып, service account e-mail-іне **Editor** құқығын беріңіз
5. Админ панелі → ⚙ Баптау → Google Sheets:
   - **Spreadsheet ID** — URL-дегі `/d/<ID>/edit` бөлігі
   - **Service Account JSON** — жүктелген кілттің толық мазмұны
   - ☑ Интеграцияны қосу → **Сақтау**
6. **↻ Синхрондау** — барлық нәтижені бірден жазады

Осыдан кейін әр ойын аяқталғанда нәтиже автоматты түрде қосылып отырады.

Балама ретінде `.env` арқылы да баптауға болады:

```env
GOOGLE_SHEETS_ENABLED=true
GOOGLE_SHEETS_ID=1AbCdEfGhIjKlMnOpQrStUvWxYz
GOOGLE_SERVICE_ACCOUNT_JSON={"type":"service_account", ...}
```

## 🔌 API анықтамасы

Барлық күй өзгертетін сұраныстар `X-CSRF-Token` тақырыбын талап етеді
(`GET /api/csrf-token` арқылы алынады).

### Ойын

| Метод | Жол | Сипаттама |
|---|---|---|
| `GET` | `/api/health` | Сервер күйі |
| `GET` | `/api/csrf-token` | CSRF токені |
| `POST` | `/api/game/register` | Студентті тіркеу → JWT |
| `GET` | `/api/game/tasks` | Тапсырмалар (жауап кілттерінсіз) |
| `GET` | `/api/game/me` | Әрекет күйі 🔒 |
| `POST` | `/api/game/attempt/start` | Жаңа әрекет бастау 🔒 |
| `POST` | `/api/game/answer` | Жауапты тексеру 🔒 |
| `POST` | `/api/game/room/complete` | Бөлмені аяқтау 🔒 |
| `POST` | `/api/game/attempt/finish` | Ойынды аяқтау 🔒 |

### Админ

| Метод | Жол | Сипаттама |
|---|---|---|
| `POST` | `/api/admin/login` | Кіру (bcrypt) |
| `POST` | `/api/admin/logout` | Шығу 🔑 |
| `GET` | `/api/admin/students` | Тізім + `?search=&group=&institution=` 🔑 |
| `GET` | `/api/admin/students/:id` | Студент карточкасы 🔑 |
| `GET` | `/api/admin/stats` | Толық статистика 🔑 |
| `GET` | `/api/admin/export/excel` | Excel экспорты 🔑 |
| `GET` | `/api/admin/export/pdf` | PDF есебі 🔑 |
| `GET` | `/api/admin/tasks` | PDF тапсырмалар туралы (`?reload=1`) 🔑 |

## 🛡 Қауіпсіздік

| Қорғаныс | Іске асыру |
|---|---|
| **Helmet** | CSP, HSTS, X-Frame-Options, nosniff және т.б. |
| **bcrypt** | Админ паролі 12 раундпен хештеледі |
| **JWT** | Бөлек ойыншы (6с) және админ (8с) токендері, httpOnly cookie |
| **CSRF** | Double-submit cookie + `timingSafeEqual` салыстыру |
| **Rate Limiting** | Жалпы 600 сұр./15мин, авторизация 20 сұр./15мин |
| **SQL Injection** | 100% параметрленген сұраныстар, жолдар ешқашан біріктірілмейді |
| **XSS** | DOM `textContent` арқылы құрылады, `innerHTML` мүлдем қолданылмайды |
| **Input Validation** | express-validator + Unicode-ті қолдайтын regex |
| **Жауап кілттері** | Клиентке ешқашан жіберілмейді — тексеру тек серверде |
| **Ұпай есептеу** | Сервердегі жауап журналынан есептеледі, клиентке сенбейді |
| **Файл жүктеу** | Тек `application/pdf`, максимум 25 МБ, тіркелген файл аты |

> ⚠️ **Production-да міндетті түрде** `JWT_SECRET` мәнін ұзын кездейсоқ жолға
> ауыстырыңыз және админ паролін өзгертіңіз:
>
> ```bash
> node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
> ```
